## 1. 模块概述

### 1.1 定位

多功能计算器是 AMEToolbox 的通用计算模块，面向工厂现场的高频计算场景：
产线参数换算、工件几何量估算、质量体积估算、货币折算、进制换算等。
模块以**科学计算器**为核心，其余 5 类计算器为辅助工具，统一在同一页面内通过顶部选择器切换。

### 1.4 设计原则

- **统一入口**：6 个计算器通过顶部 `DropdownMenu<CalculatorType>` 在同一页面切换。
- **统一历史**：所有计算器均保存最近 20 条历史；`CalculationHistory` 通过 `metadata` 字段保留各计算器输入参数，支持返回模块时精确回填。
- **离线优先**：汇率数据可手动刷新并本地缓存，无网络时允许使用缓存并提示“离线缓存”。
- **不侵入底座**：模块所有代码位于 `modules/calculator/`，不修改 `lib/core/` 及以下底座实现。
- **严格 MD3**：所有组件、颜色、形状、排版均遵循 Material Design 3 规范，优先使用 Flutter 内置 MD3 组件，不自定义视觉样式。

## 3. 详细功能规格

### 3.1 科学计算器（C-01）

#### 3.1.1 表达式语法

```ebnf
expression := term { ('+' | '-') term }
term       := factor { ('*' | '/' | '%') factor }
factor     := power { '^' power }
power      := unary
unary      := ('+' | '-') unary | primary
primary    := number | constant | function '(' expression ')' | '(' expression ')'
number     := digit+ ['.' digit*]
constant   := 'pi' | 'e'
function   := 'sin' | 'cos' | 'tan' | 'asin' | 'acos' | 'atan'
            | 'log' | 'ln' | 'sqrt' | 'abs' | 'fac'
```

#### 3.1.2 运算符与符号映射

| 界面显示 | 内部表示 | 语义 |
|----------|----------|------|
| `+` | `+` | 加法 |
| `-` | `-` | 减法 / 负号 |
| `×` | `*` | 乘法 |
| `÷` | `/` | 除法 |
| `^` | `^` | 乘方 |
| `%` | `/100` | 百分号（仅对紧邻数字生效，如 `50%` → `0.5`） |
| `(` `)` | `(` `)` | 括号，支持嵌套 |

#### 3.1.3 函数与常数

| 名称 | 参数 | 说明 |
|------|------|------|
| `sin` / `cos` / `tan` | 1 | 三角函数，受 DEG/RAD 模式影响 |
| `asin` / `acos` / `atan` | 1 | 反三角函数，输出结果按当前角度模式表示 |
| `log` | 1 | 以 10 为底的对数 |
| `ln` | 1 | 自然对数 |
| `sqrt` | 1 | 平方根 |
| `abs` | 1 | 绝对值 |
| `fac` | 1 | 阶乘，仅接受非负整数，结果过大时返回 `Error` |
| `π` / `e` | 0 | 常数 |

#### 3.1.4 显示规则

- 当前表达式在结果区上半部实时显示，字号随字符长度自适应缩小（最小 24sp，最大 56sp）。
- 计算结果按设置的小数精度四舍五入显示；超出精度末尾 0 省略。
- 开启科学计数法后，结果统一以 `aE+n` / `aE-n` 显示（例如 `1.234568E+8`）。
- 错误时结果显示 `Error`，下方小字显示具体原因（如“除数不能为零”“负数不能开平方”）。

#### 3.1.5 键盘布局

完整键盘采用**4 列竖版布局**，所有按键均使用 Material Design 3 内置按钮组件，不得自定义视觉样式：

- **数字键**（`0-9`、`.`、`Ans`）：`FilledButton.tonal`
- **编辑键与等号**（`C`、`⌫`、`=`）：`FilledButton`
- **算符与函数键**（`%`、`÷`、`×`、`-`、`+`、三角、对数、常数、括号、幂根等）：`OutlinedButton` 或 `TextButton`
- **布局分区**：
  - 上方区域：高级算符与函数；
  - 左下区域：数字小键盘；
  - 数字区上方一行及右侧一列：基础算符与编辑键。

**完整键盘（`showFullKeyboard = true`）**

```text
┌──────────────────────────┐
│  sin   cos   tan   2nd   │  高级算符/函数（OutlinedButton / TextButton）
│  log    ln    π     e    │
│   ^     √     (     )    │
│  EXP   fac   abs         │
├──────────────────────────┤
│   C     %     ×     ÷    │  基础算符：数字区上方一行（FilledButton / OutlinedButton）
│   7     8     9     -    │  数字区（FilledButton.tonal）+ 右侧算符列
│   4     5     6     +    │
│   1     2     3     =    │
│   0     .    Ans    ⌫    │
└──────────────────────────┘
```

- `EXP`：在表达式中插入 `*10^`，用于输入科学计数法（如 `1.5EXP3` → `1.5*10^3`）。
- `Ans`：填入上一次计算结果。
- `2nd`：切换第二功能键，显示 `asin` / `acos` / `atan` / `DEG` / `RAD` 等。
- 角度模式 `DEG` / `RAD` 通过 `2nd` 面板或结果区下方的 `SegmentedButton` 切换。
- 数字区固定在左下角区域；基础算符围绕数字区的**上方一行**（`C`、`%`、`×`、`÷`）和**右侧一列**（`-`、`+`、`=`、`⌫`）分布，形成包围结构。

**精简键盘（`showFullKeyboard = false`）**

- 隐藏数字键 `0-9` 与小数点 `.`，仅保留运算符、函数、常数、`=`、`C`、`⌫`。
- 用户通过物理键盘或系统软键盘输入数字。

#### 3.1.6 历史记录

- 所有计算器类型均保存历史，最多 20 条；仅保存计算成功或有效换算结果，不保存错误记录。
- 每条记录包含：`expression`（原始表达式/输入描述）、`result`（格式化结果）、`timestamp`（UTC）、`calculatorType`（计算器类型）、`metadata`（各计算器特有的输入参数，如单位、几何体、气体类型等）。
- 科学计算器额外保留 `angleMode`（DEG/RAD）。
- 竖屏：点击右上角历史入口进入全屏历史页。
- 横屏：历史面板作为右/左列固定显示。
- 历史项交互：
  - 单击“返回”图标：将表达式/输入参数回填到对应计算器。
  - 菜单“回填结果”：将结果值追加到当前输入。
  - 长按 / 右键：删除单条。
  - 顶部菜单：清空全部历史。

#### 3.1.7 角度模式

- 提供 `DEG` / `RAD` 切换按钮，默认 `DEG`。
- 切换后立即影响后续三角函数计算；当前结果不重新计算。
- 历史记录保留每次计算的角度模式，回填后保持该模式。

#### 3.1.8 错误处理

| 错误场景 | 提示文案 |
|----------|----------|
| 除零 | `除数不能为零` |
| 负数开平方 | `负数不能开平方` |
| 对数非正数 | `对数真数必须大于零` |
| 括号不匹配 | `括号不匹配` |
| 语法错误 | `表达式格式错误` |
| 阶乘非整数/负数 | `阶乘只能对非负整数求值` |

### 3.2 标准立方米-质量转换（C-02）

#### 3.2.1 功能说明

用于气体流量计常见场景：将**标准立方米（Nm³）**按气体摩尔质量换算为气体质量，或由质量反推标准立方米。

本模块基于**理想气体标准摩尔体积**计算：

```text
标准状态：温度 0°C（273.15 K）、压力 101.325 kPa（1 标准大气压）
标准摩尔体积 Vm = 22.414 L/mol = 0.022414 Nm³/mol
```

通过选择气体类型自动填充摩尔质量，也支持自定义摩尔质量与标准摩尔体积，以覆盖混合气、不同标准状态（如 20°C）等场景。

#### 3.2.2 输入项

| 字段 | 类型 | 说明 |
|------|------|------|
| 气体类型 | 下拉选择 | 天然气（甲烷）、空气、氧气、氮气、氢气、二氧化碳、丙烷、自定义 |
| 摩尔质量 `M` | 数字输入 | 单位 `g/mol`；选择气体后自动填充；自定义时手动输入 |
| 标准摩尔体积 `Vm` | 数字输入 | 单位 `L/mol`；默认 22.414；可修改以适配不同标准状态 |
| 标准体积 | 数字输入 | 可选单位：Nm³、m³、L |
| 质量 | 数字输入 | 可选单位：kg、g、t、lb、oz |

#### 3.2.3 计算规则

所有计算统一归一化到标准立方米（Nm³）和千克（kg）：

```text
质量(kg) = 标准体积(Nm³) × 摩尔质量(g/mol) ÷ 标准摩尔体积(L/mol)
标准体积(Nm³) = 质量(kg) × 标准摩尔体积(L/mol) ÷ 摩尔质量(g/mol)
```

推导：1 Nm³ = 1000 L，物质的量 `n = (V_Nm³ × 1000) / Vm`，质量 `m = n × M / 1000`。

- 用户在**标准体积**或**质量**任一字段输入并确认（失去焦点或点击计算按钮）后，自动计算另一字段。
- 两个字段均非空时，以**最后一次被编辑的字段**为基准重新计算。
- 修改气体类型、摩尔质量或标准摩尔体积后，以当前基准字段重新计算另一字段。
- 摩尔质量、标准摩尔体积必须大于 0；标准体积、质量必须大于等于 0。
- 页面实时显示**推导标准密度** `ρ = M / Vm`（kg/Nm³），便于与流量计铭牌对比。

#### 3.2.4 标准体积单位换算到 Nm³

> 在本模块中，`m³` 指标准工况下的立方米，换算系数与 `Nm³` 相同。

| 单位 | 换算系数（到 Nm³） |
|------|--------------------|
| Nm³ | 1 |
| m³ | 1 |
| L | 1e-3 |

#### 3.2.5 内置气体摩尔质量表

| 气体 | 摩尔质量 (g/mol) | 推导标准密度 (kg/Nm³) | 备注 |
|------|------------------|------------------------|------|
| 天然气（甲烷） | 16.04 | 0.716 | 以甲烷近似 |
| 空气 | 28.97 | 1.293 | 干空气 |
| 氧气 | 31.998 | 1.428 | O₂ |
| 氮气 | 28.013 | 1.250 | N₂ |
| 氢气 | 2.016 | 0.0899 | H₂ |
| 二氧化碳 | 44.01 | 1.964 | CO₂ |
| 丙烷 | 44.10 | 1.967 | C₃H₈ |
| 自定义 | 用户输入 | 用户输入 | 用于混合气或非标准状态 |

#### 3.2.6 质量单位换算到 kg

| 单位 | 换算系数（到 kg） |
|------|-------------------|
| kg | 1 |
| g | 1e-3 |
| t | 1000 |

### 3.3 单位转换器（C-03）

#### 3.3.1 支持类别与单位

| 类别 | 单位列表 |
|------|----------|
| 长度 | mm、cm、m、km、in、ft、yd、mi |
| 重量 | mg、g、kg、t、oz、lb、st |
| 温度 | °C、°F、K |
| 面积 | mm²、cm²、m²、ha、km²、in²、ft²、ac |
| 体积 | mL、L、m³、cm³、ft³、gal(US)、pt(US) |
| 速度 | m/s、km/h、mph、kn、ft/s |
| 时间 | ms、s、min、h、d、wk、mo、y |
| 角度 | deg、rad、grad |

#### 3.3.2 交互规则

- 顶部 `DropdownMenu` 选择类别；窗口缩窄时 `DropdownMenu` 自动折叠，避免 `SegmentedButton` 挤压。
- 下方两列：左侧“输入”数值框 + 源单位选择器；右侧“结果”只读框 + 目标单位选择器。
- 数值输入框支持物理键盘输入与模块内 `NumericKeypad`（MD3 按钮组件）输入。
- 输入任意一侧数值，另一侧实时换算。
- 提供“交换”按钮，同时交换两侧单位与数值。
- 输入为空时，结果显示空或 `-`。
- 单位下拉菜单显示中文注释，如 `m（米）`、`km（千米）`。

#### 3.3.3 温度换算公式

温度属于非线性换算，不经过 `units_converter`，直接使用以下公式：

```text
°C → °F : F = C × 9/5 + 32
°F → °C : C = (F - 32) × 5/9
°C → K  : K = C + 273.15
K  → °C : C = K - 273.15
```

#### 3.3.4 精度规则

- 换算结果按模块全局小数精度设置进行四舍五入。
- 极小值（绝对值 < 1e-12）自动切换为科学计数法显示，避免 `0.000000000000`。

### 3.4 几何计算器（C-04）

#### 3.4.1 支持几何体与公式

| 几何体 | 可计算量 | 输入参数 | 公式 |
|--------|----------|----------|------|
| 圆 | 面积、周长 | 半径 `r` | 面积 `πr²`；周长 `2πr` |
| 矩形 | 面积、周长、对角线 | 长 `a`、宽 `b` | 面积 `ab`；周长 `2(a+b)`；对角线 `√(a²+b²)` |
| 长方体 | 体积、表面积 | 长 `a`、宽 `b`、高 `h` | 体积 `abh`；表面积 `2(ab+ah+bh)` |
| 圆柱 | 体积、表面积、侧面积 | 半径 `r`、高 `h` | 体积 `πr²h`；侧面积 `2πrh`；表面积 `2πr(r+h)` |
| 圆锥 | 体积、表面积、侧面积 | 半径 `r`、高 `h`、母线 `l`（可选） | `l` 为空时 `l = √(r²+h²)`；体积 `(1/3)πr²h`；侧面积 `πrl`；表面积 `πr(r+l)` |
| 球 | 体积、表面积 | 半径 `r` | 体积 `(4/3)πr³`；表面积 `4πr²` |
| 圆筒（空心圆柱） | 体积、表面积 | 外径 `R`、内径 `r`、高 `h` | 体积 `π(R²-r²)h`；表面积 `2πRh + 2πrh + 2π(R²-r²)` |
| 棱锥（正多边形底） | 体积、表面积 | 底边数 `n`、边长 `a`、高 `h` | 底面积 `(n a²)/(4 tan(π/n))`；体积 `(1/3) × 底面积 × h`；表面积 = 底面积 + 侧面积，侧面积 `(n a s)/2`，其中 `s = √(h² + (a/(2 tan(π/n)))²)` |

#### 3.4.2 交互规则

- 顶部选择几何体。
- 动态显示所需输入字段；输入后立即计算所有可计算量。
- 数值输入框支持模块内 `NumericKeypad`（MD3 按钮组件）输入，同时支持物理键盘输入。
- 结果以卡片列表形式展示，每个结果标注名称与数值。
- 提供“公式说明”展开项，显示当前几何体的公式（纯文本）。

#### 3.4.3 输入校验

- 所有尺寸必须大于 0。
- 圆筒要求外径 `R > 内径 r`。
- 棱锥要求底边数 `n ≥ 3` 且为整数。

### 3.5 进制转换器（C-05）

#### 3.5.1 支持进制

| 进制 | 前缀（输入可带） | 有效字符 |
|------|------------------|----------|
| 二进制 | `0b` / `0B` | `0-1` |
| 八进制 | `0o` / `0O` | `0-7` |
| 十进制 | 无 | `0-9`、`.` |
| 十六进制 | `0x` / `0X` | `0-9`、`a-f`、`A-F` |

#### 3.5.2 转换规则

- 在任意进制输入框输入时，其他进制输入框实时同步显示。
- 支持整数和有限小数：
  - 十进制小数转二进制最多保留 8 位，超出时截断并提示“二进制小数已截断”。
  - 非十进制的小数仅支持二进制、八进制、十六进制转十进制，暂不支持相互转小数。
- 输入非法字符时，输入框拒绝输入并震动反馈（仅触控）。

#### 3.5.3 其他功能

- “复制结果”按钮：将当前所有进制结果拼接为文本复制到剪贴板。
- 十进制输入框支持负数；其他进制框仅支持正数。

### 3.6 汇率计算器（C-06）

#### 3.6.1 支持货币

默认支持 12 种常见货币：
`CNY`、`USD`、`EUR`、`JPY`、`GBP`、`HKD`、`KRW`、`AUD`、`CAD`、`CHF`、`SGD`、`RUB`。

#### 3.6.2 汇率来源

- 默认公开源：`https://open.er-api.com/v6/latest/{base}`，返回以 `{base}` 为基准的汇率表。
- 用户可在模块设置中自定义源地址，地址中必须包含 `{base}` 占位符；模块将其替换为当前基准货币。
- 自定义源返回 JSON 格式需满足：
  - 顶层字段 `rates` 为 `{货币代码: 汇率}` 的 Map。
  - 可选字段 `time_last_update_utc` 用于显示更新时间。

#### 3.6.3 换算规则

- 选择源货币与目标货币，输入金额后实时换算：
  ```text
  目标金额 = 源金额 × (rates[目标] / rates[源])
  ```
- 切换源货币时，自动重新请求该基准货币的汇率表。
- 切换目标货币时，仅使用当前缓存汇率表计算，不重新请求。

#### 3.6.4 刷新与缓存

- 手动刷新按钮：立即请求网络并更新缓存。
- 网络失败时：
  - 若存在缓存，使用缓存并显示“离线缓存（更新时间：xx）”。
  - 若无缓存，显示“暂无汇率数据，请检查网络”。
- 缓存结构见 §4.3。

class CalculatorConfig {

class CalculationHistory {

## 5. 页面与布局规格

### 5.1 总体布局

#### 竖屏（Portrait）

```text
┌────────────────────────────────────────────┐
│ [类型▼] [sci 计数法]        多功能计算器 [🕓] │  ← AppBar
├────────────────────────────────────────────┤
│                                            │
│              结果显示区                     │  ← 占竖屏 20%-25%
│         （近期 3 条历史缩略）                │
│                                            │
├────────────────────────────────────────────┤
│              计算器主体区                   │  ← 随 CalculatorType 变化
├────────────────────────────────────────────┤
│              数字/函数键盘                  │  ← 可隐藏
└────────────────────────────────────────────┘
```

- 右上角历史入口按钮在竖屏时始终显示，所有计算器类型均可进入历史页面。
- 顶部控制区采用 `Wrap` 或 `Row` + `Spacer`，保证类型选择器、科学计数法开关与历史按钮不拥挤；必要时自动换行。

#### 横屏（Landscape）

```text
┌─────────────┬──────────────────────────────────────┐
│             │  [类型▼] [sci 计数法]  多功能计算器   │
│  历史结果   │                                      │
│   面板      │           计算器主体区                │
│             │                                      │
│             ├──────────────────────────────────────┤
│             │           数字/函数键盘               │
└─────────────┴──────────────────────────────────────┘
```

- 横屏分为两列：左侧默认计算器，右侧历史面板。
- 设置中 `historyPanelOnLeft = true` 时，左右交换。
- 横屏**不显示**右上角历史入口按钮。

### 5.2 顶部控制区

| 控件 | 位置 | 显示条件 | 说明 |
|------|------|----------|------|
| 计算器类型下拉 | AppBar 左侧 | 始终显示 | `DropdownMenu<CalculatorType>`，带图标 |
| 科学计数法 Switch | AppBar 标题下方 / 右侧 | 仅科学计算器 | 标签“科学计数法” |
| 历史入口按钮 | AppBar 右侧 | 竖屏 | 图标 `history`，所有计算器类型可见 |
| DEG/RAD 切换 | 结果区下方 | 仅科学计算器 | `SegmentedButton` |

### 5.3 结果显示区

- 高度占竖屏约 20%-25%，随字体缩放设置自适应。
- 科学计算器：上方显示当前表达式，下方大字显示结果；结果下方以小字滚动显示最近 3 条历史。
- 其他计算器：显示关键结果（如标准立方米-质量的双向结果、单位换算的结果、几何计算结果列表）。

### 5.4 键盘显示规则

- 设置中“键盘显示”开关（`showFullKeyboard`）关闭后，科学计算器主画面隐藏数字键 `0-9` 与小数点 `.`，仅保留运算符、函数、常数与 `=`。
- 非科学计算器（单位换算、几何、标准立方米-质量）统一使用模块内 `NumericKeypad`（MD3 按钮组件）输入；输入框同时保持可聚焦，支持物理键盘双输入。进制、汇率计算器保留 `TextField` 输入。

## 7. 首页仪表盘规格

### 7.1 卡片一：快速计算器

- 显示一个极简表达式输入框，支持四则运算、括号、常用函数。
- 受设置“键盘显示”影响：可在卡片内显示精简数字键盘，或仅显示表达式输入框。
- 卡片内直接显示计算结果。
- 点击卡片进入模块主页（科学计算器）。

### 7.2 卡片二：最近计算历史

- 显示最近 3-5 条科学计算器历史（表达式 + 结果）。
- 点击某条历史项进入模块主页并回填表达式。
- 无历史时显示“暂无计算记录”。

### 7.3 显示规则

- 两个卡片可在模块设置中独立开关。
- 都开启时，按 `dashboardQuickCalcOrder` / `dashboardHistoryOrder` 排序。
- 卡片尺寸、圆角、阴影遵循底座 `ModuleCardWidget` 规范。
